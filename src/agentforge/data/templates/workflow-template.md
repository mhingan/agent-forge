# [Workflow name]

**Purpose:** State the outcome and when to use this playbook.

## Scope and prerequisites

- Authorized scope and owner.
- Required inputs, versions, permissions, and environment.
- Dependencies and known exclusions.
- Safety/approval gates.

## Phase 1 — Discover

List the source-of-truth files, systems, evidence, and assumptions to inspect.

**Gate:** State what must be understood before continuing.

## Phase 2 — Plan

Define steps, dependencies, affected assets, risk, validation, and recovery.

**Gate:** State approval or readiness criteria.

## Phase 3 — Execute

Describe the safe ordered actions. Identify irreversible steps and stop conditions.

## Phase 4 — Verify

Define exact tests, checks, expected results, and failure behavior.

## Phase 5 — Handover

Specify report format, owners, documentation, monitoring, and follow-up.

## Stop conditions

List actions that must stop pending user or owner approval.

## Completion standard

Define observable success, evidence, and remaining risks.
