# Accessibility audit checklist

## Scope
- Pages/components:
- Critical journeys:
- Standard/level/target:
- Browsers and platforms:
- Screen readers/input methods:
- Known exclusions:

## Per-page checks
- [ ] Landmark and heading hierarchy.
- [ ] Semantic controls and meaningful accessible names.
- [ ] Keyboard access and logical tab order.
- [ ] Visible focus and no keyboard trap.
- [ ] Dialog/menu focus entry, containment, Escape, and restoration.
- [ ] Labels, instructions, validation, and error association.
- [ ] Contrast and status not conveyed by color alone.
- [ ] Zoom/text scaling without clipping.
- [ ] Reduced motion and non-flashing behavior.
- [ ] Alternative text, captions, transcripts, and data alternatives.
- [ ] Dynamic status announcements without excessive noise.
- [ ] Responsive/touch target behavior.

## Verification record
List exact automated tools, browser/OS, screen reader, keyboard journeys, viewport/zoom, results, and remaining limitations. An automated scan alone is not a conformance assessment.
